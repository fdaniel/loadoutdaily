Privacy Policy

Loadout Daily and Loadout Daily Uploader · Last updated 24 October 2026

Who this covers

This policy covers this website and Loadout Daily Uploader, a desktop tool that the owner of the Loadout Daily YouTube channel uses to upload the channel's own videos. The tool is used only by the channel's owner, on their own computer.

Use of YouTube API Services

Loadout Daily Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

What data the tool uses

  • Sign-in permission (OAuth token): when the owner connects their YouTube channel, Google gives the tool a token that allows it to upload videos (youtube.upload) and read basic channel information such as the channel name (youtube.readonly).
  • Upload results: the ID and link of each uploaded video, so the owner can see what was published.

The tool does not read, collect or store data about viewers, subscribers, comments or any other YouTube user.

Where the data is kept

The token and upload results are stored only on the owner's own computer, in a file readable only by the owner. They are not sent to any server other than Google's, and they are never sold, shared or used for advertising.

How long data is kept and how it is deleted

The sign-in token is kept only while the channel stays connected. Upload results are kept while the owner uses the tool. If access is removed (see below), the token and all stored YouTube data are deleted from the owner's computer within 7 days. The owner can also delete them at any time by deleting the tool's data folder.

How to remove access

Access can be removed at any time on the Google security settings page (Third-party apps with account access). Deleting the tool's token file on the owner's computer also removes it.

This website

This website uses no cookies, analytics or tracking. It is hosted by GitHub Pages, which may keep standard server logs (see the GitHub Privacy Statement).

Changes and contact

If this policy changes, the new version will be posted on this page with a new date. For questions, email loadoutdailynews@gmail.com.
